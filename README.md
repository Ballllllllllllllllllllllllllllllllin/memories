# memories ❤️

Готовый шаблон сайта-подарка с галереей воспоминаний.

## Что есть

- красивый адаптивный дизайн;
- главный экран;
- галерея фотографий;
- открытие фотографии в полноэкранном окне;
- даты и подписи к фотографиям;
- временная линия отношений;
- блок с "ожившими" воспоминаниями через видео;
- фоновая музыка;
- финальное личное послание;
- анимации при прокрутке;
- нормальная версия для телефона.

## Как добавить свои материалы

### Фотографии

Положи свои фотографии в:

`images/`

И назови их:

- `photo-01.jpg`
- `photo-02.jpg`
- `photo-03.jpg`
- `photo-04.jpg`
- `photo-05.jpg`
- `photo-06.jpg`

Либо поменяй названия файлов прямо в `index.html`.

### Ожившие фотографии

Экспортируй Live Photo в видео и положи видео в:

`videos/`

Названия:

- `memory-01.mp4`
- `memory-02.mp4`

### Музыка

Положи музыкальный файл в:

`music/song.mp3`

## Как запустить

Самый простой вариант:

1. Открой папку `memories` в VS Code.
2. Установи расширение **Live Server**.
3. Нажми правой кнопкой по `index.html`.
4. Выбери **Open with Live Server**.

Можно также просто открыть `index.html` браузером.

## Что нужно изменить под себя

В `index.html` замени:

- даты;
- названия моментов;
- описания;
- текст личного письма;
- имя в подписи.

Сайт специально сделан без базы данных и сервера — все фотографии, видео и текст находятся внутри проекта.
